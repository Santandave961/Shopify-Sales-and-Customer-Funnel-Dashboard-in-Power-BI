# Shopify-Sales-and-Customer-Funnel-Dashboard-in-Power-BI
A comprehensive Power BI dashboard for analyzing Shopify e-commerce sales data, customer behaviour and business performance metrics.

### Dashboard Overview
This Power BI report provides detailed insight into:
- Transaction Performance: Total Sales, order quantities and average order values.
- Customer Analysis: Customer segmentation, purchase behaviour and retention metrics.
- Geographic Distribution: Regional sales performance across provinces and cities.
- Payment Method: Analysis of payment gateway usage and preferences
- Product Performance: Sales breakdown by product categories
- Time-based Trends: Sales trends over time with seasonal analysis.


# Key Metrics Displayed
- Net Sales: $4.18M total revenue.
- Total Orders: 7534 transactions.
- Average order value: $562.6
- Total Customers: 4,431 unique customers.
- Customer retention: 46% repeat rate.
- Lifetime Value: $943.6 average per customer.
